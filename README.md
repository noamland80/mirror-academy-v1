# MIRROR Interactive Sales Academy — `mirror-academy-v1`

A bilingual (EN/ES) training application for aesthetic-clinic consultations, built on
the MIRROR Method from *The Beauty Sales Secrets* and the canonical MIRROR architecture
(8 phases, 7 trust stages, 6 trust standards, 4 ethical duties, Toolkits #1–24).

## Release control

**This is a separate build.** `mirror-wow-v1-20260901` is untouched and remains the
release candidate under Architecture review. This tree forks its engine layer and adds
the Academy on top; it must not be merged into that RC without an explicit decision.

## What is in this build

| Area | State |
|---|---|
| Curriculum | **10 of 10 modules built** — 60 interactive lessons, 659 minutes of teaching |
| Exercises | 320 blocks, 18 distinct exercise types, 72% interactive rather than reading |
| Consultations | **9 full cases** across nine distinct commercial failures — fear, identity, over-agreement, price, unrealistic expectation, genuine uncertainty, distrust after a bad prior experience, third-party influence, existing-client complacency — 8 phases each, derived YES / DEFER / NO |
| Languages | Full EN/ES parity: navigation, lessons, exercises, cases, feedback, toolkit workspaces, progress, manager view, and the canonical framework's own labels |
| Toolkits | #1, #3, #4, #5, #6, #8 executable in context, with case-aware honesty validation |
| Manager | Coaching view: who is practising / what repeats / where the team loses trust / what to coach this week / what the evidence is / what changed after coaching — evidence sentences with counts, drawn as pattern graphics, never scores |
| Field work | Every module ends with an assignment for a real consultation; the journal asks what happened, and refuses a one-line answer |
| Two MIRROR layers | The 6-step book method and the 8-phase architecture are reconciled, never collapsed — taught in Module 1 lesson `m1l6`, generated from `server/framework/method.js`, with the three places the six do not cover the eight stated explicitly |
| Credentials | The three demo passwords published to the public repo are burned: `MIRROR_MODE=hosted` refuses them and re-proves it against the live database at boot |

## Run

```bash
npm install
npm start                 # http://localhost:5000
npm run seed:demo         # realistic team activity so the manager view demonstrates itself
npm test                  # engine + academy API suites
node test/verify-content.js   # curriculum structure, answer keys and bilingual parity
```

Seeded accounts are printed on first start.

## Depth audit

Counts are not the acceptance test. `node scripts/depth-audit.js` samples fifteen lessons
(stratified so no module escapes review), demands of each a distinct concept, a source, a
practised behaviour, at least two explained decisions and a transfer assignment, and
screens all sixty lessons for near-duplication, thin Spanish and reading-only content.
`ACADEMY_DEPTH_AUDIT.md` records what it rejected, what changed as a result, and three
full learner journeys — novice, experienced high performer, manager — with an honest
verdict on each. It also records one instrument correction: two Spanish-depth heuristics
were withdrawn after every leaf they flagged proved to be correct idiomatic Spanish.

## Provenance

`BOOK_MIRROR_CONTENT_MAP.md` is generated by `node scripts/build-provenance.js` from the
live curriculum: it maps every one of the 60 lessons to its book chapter and section and
to its canonical anchor, and the generator fails if a lesson has no entry. Section 1 of that map is generated from `server/framework/method.js` and joins the book's
six-step method to the eight-phase architecture, letter by letter, including the three
phases the six letters do not name. The last section lists what is **not** from the book —
the canonical architecture — so the two sources are never conflated. No framework in this
build is invented, and the book is never credited with teaching the eight phases.
